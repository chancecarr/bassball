### Explanation

Bassball is a personal project inspired by the 2020 pandemic-era baseball simulator [Blaseball](https://blaseball.com). My project will simulate and show the play-by-play of baseball games on the hour every hour. Eventually I want to build a live stats database and past-game replay functionality.

I have already gone through a couple of iterations of my codebase, with this repo being the newest.

These are my main purposes for the project:

- Practice software architecture principles, including utilizing relevant patterns (Model-View-Controller, Event-Based architecture)
- Dive deep into stdio and learn how to display the game in an elegant way on a terminal interface
- Eventually, move the game hosting into the cloud so my portfolio site has a live component that can also showcase my devops & AWS skills
